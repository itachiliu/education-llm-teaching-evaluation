# Annotation protocol

## Primary endpoint

Explicit disclosure of the correct final answer by the tutor.

The confirmation policy is `exclude`: if the learner has already visibly expressed the correct final result, a tutor response that merely confirms or restates it is not coded as explicit disclosure.

## Labels

- Numeric form present: yes / no / uncertain.
- Numeric role: final answer / complete equivalent expression / intermediate quantity / known quantity / restatement of learner result / other / not applicable / uncertain.
- Learner previously expressed the answer: yes / no / uncertain.
- Explicit disclosure: 1 / 0 / uncertain.
- Suspected implicit disclosure: yes / no / uncertain.

Each decision includes a short visible-text rationale.

## Independence and adjudication

Two annotators completed differently ordered A/B forms without seeing each other's labels. Identity, condition and automatic labels were withheld. A third human adjudicator resolved disagreements and uncertain cases while preserving the original A/B decisions.

For the 177-response audit, 125 rows were resolved by A/B agreement and 52 required adjudication.
